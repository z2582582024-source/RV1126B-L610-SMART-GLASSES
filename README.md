## 📖 作品简介
根据调查发现，在现有的精密维修与高危作业等过程中，主要依靠人力手动操作设备或查阅图文资料来进行信息检索。在这个过程中，由于人员双手往往被占用，视线必须在作业目标与查询终端之间频繁切换，不仅信息获取的效率极其低下，更极易因注意力分散带来安全隐患。为解决以上的问题，帮助用户彻底解放双手并实现“所见即所得”的直觉式交互，我们团队基于RV1126B计算平台，采用红外眼球追踪、第一视角图像处理、L610 4G物联网通信及云端大模型等技术实现视线锚定多模态问答（Look & Ask）、全天候智能语音交互。

## 🧠 核心功能
- 高精度视线空间锚定
- 端侧双 AI 模型离线推理
- 端云协同多模态认知
- 双进程解耦高可靠系统
- 可联网将图片上传至云端进行大模型推理
